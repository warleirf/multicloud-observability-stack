# 📊 Multi-Cloud Observability Stack

> Solução containerizada e automatizada de **Observabilidade Quad-Cloud** para monitoramento unificado e em tempo real de ambientes **AWS, Azure, Google Cloud (GCP) e Oracle Cloud (OCI)**.

## 🚀 Sobre o Projeto

O **Multi-Cloud Observability Stack** entrega uma arquitetura moderna de monitoramento unificado 100% orquestrada via **Docker Compose**. O projeto une a capacidade robusta de alerta e auto-descoberta do **Zabbix Server (v6.4 Alpine)** com banco **PostgreSQL (v15)** ao poder de visualização executiva do **Grafana (v10.1)**.

### 🛠️ Diferenciais da Solução:
- **Provisionamento Automatizado:** Data Sources pré-configurados para **AWS CloudWatch**, **Azure Monitor**, **GCP Cloud Monitoring**, **OCI Metrics** e **Zabbix**.
- **Pronto para Produção:** Variáveis de ambiente centralizadas em `.env` e persistência de dados em volumes nomeados.
- **Leve e Escalável:** Baseado em imagens oficiais Alpine Linux para menor consumo de recursos.
